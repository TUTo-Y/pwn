# 内核符号查找

## 常见加载地址

内核基地址在未开启kaslr默认加载位置为 `0xffffffff81000000`
内核驱动在未开启kaslr默认加载位置为 `0xffffffffc0000000`

## 常见符号

init_cred
commit_creds
prepare_kernel_cred
modprobe_path
swapgs_restore_regs_and_return_to_usermode
ptmx_fops


## 查找静态地址

### python

```python
elf = ELF('./vmlinux', checksec=False)
def get_symbols_info(elf, symbol_name):
    return log.success("u64 " + symbol_name + " = " + hex(elf.symbols[symbol_name]) + ';')

log.success("u64 kernel_base = " + hex(elf.address) + ';')
get_symbols_info('init_cred')
get_symbols_info('commit_creds')
get_symbols_info('prepare_kernel_cred')
get_symbols_info('modprobe_path')
get_symbols_info('swapgs_restore_regs_and_return_to_usermode')
get_symbols_info('ptmx_fops')
```

## 查找动态地址

### /proc/modules

查看驱动加载地址

```bash
cat /proc/modules
```

### /proc/kallsyms

`/proc/kallsyms`保存着所有符号的动态地址

```bash
cat /proc/kallsyms | grep "_stext"
cat /proc/kallsyms | grep "init_cred"
cat /proc/kallsyms | grep "commit_creds"
cat /proc/kallsyms | grep "prepare_kernel_cred"
cat /proc/kallsyms | grep "modprobe_path"
cat /proc/kallsyms | grep "swapgs_restore_regs_and_return_to_usermode"
cat /proc/kallsyms | grep "ptmx_fops"
```

### 驱动加载地址

`/sys/module/{驱动名}/sections/`下保存该驱动的所有段实际地址

eg: `/sys/module/core/sections/.text`中存放的是core驱动的.text段的实际加载地址

```bash
cat /sys/module/core/sections/.text
```
